## 🔐 Vercel Domain Verification Setup (`OPENAI_APPS_CHALLENGE_TOKEN`)

When submitting to OpenAI Plugin Directory, OpenAI requires domain ownership verification via a challenge token at `/.well-known/openai-apps-challenge`.

Follow these steps to set the token:
1. Log in to your [Vercel Dashboard](https://vercel.com).
2. Go to your project (`food-recommendation-mcp`) → **Settings** → **Environment Variables**.
3. Add a new variable:
   - **Key:** `OPENAI_APPS_CHALLENGE_TOKEN`
   - **Value:** `<Paste the challenge token generated by OpenAI Portal>`
   - **Environment:** Select *Production*, *Preview*, and *Development*.
4. **Redeploy the project**: Go to **Deployments** → Click on the latest deployment → Select **Redeploy** (so the new environment variable is loaded into the runtime).
5. Test in browser or curl:
   ```bash
   curl https://food-recommendation-mcp.vercel.app/.well-known/openai-apps-challenge
   ```
   It should return your challenge token as plain text.

## 📋 OpenAI Developer Dashboard Next Steps

Once the ZIP is prepared and the domain challenge token is deployed:
1. **Verify Domain**: In the OpenAI Developer Portal, click **Verify Domain**. It will ping `https://food-recommendation-mcp.vercel.app/.well-known/openai-apps-challenge` and confirm ownership.
2. **Connect & Scan Tools**: Enter the MCP Server URL (`https://food-recommendation-mcp.vercel.app/mcp`). The portal will scan and detect `search_food` and `get_top_foods`.
3. **Review Details**: Upload the plugin ZIP bundle. Verify all metadata, test cases (5 positive, 3 negative), category (`Travel`), and Loom demo video URL.
4. **Submit for Review**: Complete the submission and wait for OpenAI's review approval.

## 🚀 Quick Setup / Installation

### 1. ChatGPT / OpenAI Agent Plugins
Upload this plugin ZIP directly via the OpenAI plugin directory or developer portal:
- **Manifest:** `plugin.json` or `.codex-plugin/plugin.json`
- **Default Prompt:** `"Find top food recommendations in Jodhpur"`

### 2. Claude Desktop (`claude_desktop_config.json`)
```json
{
  "mcpServers": {
    "jodhpur-food-recommendation": {
      "type": "streamable-http",
      "url": "https://food-recommendation-mcp.vercel.app/mcp"
    }
  }
}
```

### 3. Cursor MCP Config
Add as a new MCP server in Cursor Settings -> Features -> MCP:
- **Name:** `jodhpur-food-recommendation`
- **Type:** `SSE` / `streamable-http`
- **URL:** `https://food-recommendation-mcp.vercel.app/mcp`
